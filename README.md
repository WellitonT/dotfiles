# dotfiles

Configurações do meu ambiente Linux (Ubuntu Server).

## Conteúdo
- `.bashrc`: base padrão do Ubuntu com prompt colorido
- `.vimrc`: números de linha e indentação de 4 espaços

## Instalação
```
git clone https://github.com/WellitonT/dotfiles.git ~/dotfiles
cd ~/dotfiles
./NOME-DO-SCRIPT.sh
```
O script cria links simbólicos na home apontando para estes arquivos.
